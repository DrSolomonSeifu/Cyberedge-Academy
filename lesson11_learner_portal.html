📖 Core Content: Analyzing Malicious Activity

Network Attack Indicators

🔍 Beaconing Behavior

What is it? Regular, periodic communications from a compromised system to an external command-and-control (C2) server.

Why it matters: Normal traffic is random and varied. Beaconing is methodical—same destination, same interval, predictable pattern.

Example: Infected workstation sends 128-byte packets every 10 minutes to 203.0.113.45 on port 443.

Common Network Attack Patterns

  • Traffic Spikes: Sudden 1000%+ increase in bandwidth (potential DDoS or data exfiltration)
  • Abnormal Destinations: Traffic to unusual geographic locations or known malicious IPs
  • Off-Hours Activity: Large data transfers at 2 AM when nobody's working
  • Protocol/Port Mismatches: DNS queries on port 80 instead of port 53
Indicator What It Looks Like What It Means
Beaconing Regular packets to same IP every X minutes C2 malware checking for instructions
DDoS Attack Massive traffic spike from multiple sources Attempt to overwhelm and crash systems
Port Scan Sequential connection attempts to many ports Reconnaissance before attack
Data Exfiltration Large outbound transfer to external IP Stolen data leaving the network

Rogue Devices

Definition: Unauthorized hardware or software on your network that shouldn't be there.

Types of Rogue Devices

  • Rogue Access Points: Fake WiFi networks that intercept traffic (Wi-Fi Pineapple)
  • Unauthorized Laptops/Phones: Personal devices connecting to corporate network
  • Malicious VMs: Virtual machines set up to host attacks
  • Smart IoT Devices: Printers, cameras, smart TVs with weak security
  • USB Devices: Malicious USB drives that autorun malware
Real-World Example: Target Breach (2013)
Attackers gained access through an HVAC vendor's compromised credentials. From there, they moved laterally to payment systems and stole 40 million credit card numbers. This demonstrates how a seemingly unrelated third-party device can be an entry point.

Detection Methods

  • 802.1X Authentication: Requires authentication before network access
  • DHCP Log Monitoring: Track which devices request IP addresses
  • MAC Address Filtering: Only allow known devices
  • Network Scanning: Regular Nmap scans to discover all connected devices
  • Wireless Surveys: Scan for unauthorized access points

Operating System Analysis

Windows Process Analysis

Key Tools:

  • Process Explorer: Advanced task manager showing process trees and relationships
  • Process Monitor: Real-time file/registry/network activity logging
  • TCPView: View active network connections by process
  • Autoruns: See what runs at startup (persistence mechanisms)

Critical Windows Processes to Know:

  • system.exe: Windows kernel
  • smss.exe: Session Manager
  • csrss.exe: Client Server Runtime (GUI)
  • lsass.exe: Local Security Authority (authentication)
  • services.exe: Service Control Manager
⚠️ Malware Disguise Techniques
Attackers name malware to look like legitimate processes:
  • Typos: "lsas.exe" instead of "lsass.exe"
  • Wrong Location: Real csrss.exe is in C:\Windows\System32, fake one in C:\Temp
  • Wrong Parent: Chrome.exe should NOT be spawned by Word.exe
Always verify: File location, digital signature, parent process!

Suspicious File System Changes

  • New files in system directories (C:\Windows, C:\Windows\System32)
  • Odd filenames (xyz123.exe, temp.tmp.exe)
  • Modified system files or hosts file
  • Registry changes disabling security features
  • Alternate Data Streams (hidden data in NTFS files)
  • Cleared security logs (covering tracks)
  • New unauthorized admin accounts

Data Exfiltration Methods

How attackers steal your data:

Method How It Works Detection
Email Send files as attachments to external accounts Monitor large outbound emails, personal account usage
Cloud Storage Upload to Dropbox, Google Drive, OneDrive CASB solutions, monitor cloud service connections
FTP/SFTP Transfer files to external servers Monitor FTP connections, unusual port activity
USB Devices Copy data to removable media USB logging, endpoint DLP, disable autorun
DNS Tunneling Hide data in DNS queries/responses Monitor unusual DNS patterns, query length
🔐 DNS Tunneling Explained

How it works: Attackers encode stolen data into DNS subdomain queries.

Example: Instead of normal DNS queries, you see:

ZGF0YWJhc2U.exfil.attacker.com cGFzc3dvcmRz.exfil.attacker.com

When decoded (base64), these reveal "database" and "passwords" being exfiltrated!

Detection: Look for unusually long DNS queries, high volume of queries to single domain, unusual DNS record types from workstations.

Vulnerability Assessment Tools

Purpose: Identify security weaknesses before attackers exploit them.

Major Tools

  • Nessus (Tenable): Commercial scanner with 60,000+ plugins
  • OpenVAS: Open-source alternative to Nessus
  • Nmap: Network discovery and port scanning
  • Qualys: Cloud-based continuous scanning
  • Rapid7 Nexpose: Risk-based prioritization

What They Detect

  • Missing security patches
  • Default credentials
  • Weak encryption
  • SQL injection vulnerabilities
  • Cross-site scripting (XSS)
  • Open ports and unnecessary services
  • SSL/TLS misconfigurations
  • Outdated software versions
💡 Vulnerability Prioritization
How to prioritize 1,000+ vulnerabilities:
  1. CVSS Score: Critical (9-10) first, then High (7-8.9)
  2. Exploitability: Is it being actively exploited in the wild?
  3. Asset Criticality: DMZ web server > internal print server
  4. Data Sensitivity: Systems with PII/PHI get priority
  5. Compensating Controls: Is it behind a firewall? Air-gapped?
  6. Patch Availability: Can we fix it now or waiting on vendor?

🔧 Practical Analysis Guide

How to Detect Beaconing in Wireshark

Step-by-Step Instructions
  1. Open Wireshark and load a PCAP file or start capturing
  2. Go to Statistics → Conversations → IPv4
  3. Sort by "Packets" column (descending) to find high-volume talkers
  4. Identify suspicious external IPs with regular traffic
  5. Apply filter: ip.dst == [suspicious.IP.address]
  6. Go to Statistics → I/O Graph to visualize the pattern
  7. Calculate time intervals between packets using Frame time
  8. Look for: Regular intervals (every 60s, 300s, 600s), consistent packet sizes

Investigating Suspicious Processes (Windows)

Process Explorer Investigation
  1. Download Sysinternals Suite from Microsoft
  2. Run Process Explorer as Administrator
  3. For each suspicious process, check:
    • Image Path: Right-click → Properties → Image tab. Is it in the correct location?
    • Parent Process: Does it make sense? (Chrome shouldn't be child of Word)
    • Company Name: Is it signed by a legitimate publisher?
    • Network Activity: TCP/IP tab shows connections. Any to unknown IPs?
  4. Use TCPView to see network connections in real-time
  5. Use Autoruns to check startup persistence mechanisms
  6. Red flags: Unsigned binaries, Temp directory locations, unexpected network connections

Detecting Rogue Devices

Network Scanning Approach
  1. DHCP Log Review: Check DHCP server for recently assigned IPs
  2. Compare MAC Addresses: Against authorized device database
  3. Nmap Host Discovery:
    nmap -sn 192.168.1.0/24
    This finds all active hosts
  4. OS Detection on Unknowns:
    nmap -O [suspicious.IP]
    Fingerprint the operating system
  5. MAC Vendor Lookup: Check macvendors.com or macvendorlookup.com
  6. Document findings: IP, MAC, OS, first seen date/time, location
  7. Investigate further: Physical location, user interview, port tracing

Vulnerability Scanning with Nmap

Basic Nmap Commands
Host Discovery:
nmap -sn 192.168.1.0/24
Port Scan with Service Version:
nmap -sV -sS [target.IP]
OS Detection:
nmap -O [target.IP]
Vulnerability Scanning (NSE scripts):
nmap --script vuln [target.IP]
Comprehensive Scan:
nmap -sS -sV -O -A --script vuln [target.IP]
⚖️ Legal and Ethical Reminder
ONLY scan systems you own or have explicit written permission to scan!
  • Unauthorized scanning is illegal under CFAA and similar laws
  • Always get written authorization before testing
  • Coordinate with IT teams in enterprise environments
  • Practice on intentionally vulnerable VMs (Metasploitable, DVWA, Vulnhub)
  • Never scan production systems or public networks without permission

📖 Glossary of Key Terms

Quick reference for important terminology used in this lesson.

802.1X
A network access control protocol that provides authentication for devices attempting to connect to a network. Requires valid credentials before granting access.
ADS (Alternate Data Streams)
An NTFS file system feature that allows data to be hidden within files without changing the file size or appearance. Often exploited by attackers to hide malware.
ARP Poisoning (ARP Spoofing)
Attack technique where false ARP messages are sent to associate an attacker's MAC address with a legitimate IP, allowing traffic interception and on-path attacks.
Beaconing
Regular, periodic communications from a compromised system to an external command-and-control (C2) server. Characteristic pattern: same destination, consistent interval, predictable packet size.
Botnet
Network of infected devices (bots) controlled by an attacker to perform coordinated actions like DDoS attacks, spam distribution, or cryptocurrency mining.
CASB (Cloud Access Security Broker)
Security solution that monitors and controls cloud service usage, helping detect unauthorized data uploads and enforce security policies for cloud applications.
C2 (Command and Control)
Communication channel through which attackers send commands to and receive data from compromised systems.
CVSS (Common Vulnerability Scoring System)
Standardized framework for rating vulnerability severity on a scale of 0-10 (Low, Medium, High, Critical). Helps prioritize remediation efforts.
Data Exfiltration
Unauthorized transfer of data from an organization's network to an external location. Can occur via email, cloud storage, FTP, USB, or DNS tunneling.
DDoS (Distributed Denial of Service)
Cyberattack using multiple compromised devices (botnet) to flood a target with traffic, overwhelming resources and making systems unavailable to legitimate users.
DLP (Data Loss Prevention)
Security technology that monitors and blocks unauthorized data transfers, helping prevent sensitive information from leaving the organization.
DNS Tunneling
Data exfiltration technique that encodes stolen data into DNS queries or responses to bypass security controls. Example: hiding data in subdomain names or TXT records.
Honeypot
Decoy system designed to lure attackers and study their techniques. Can also refer to malicious servers set up by attackers to trap victims.
IoC (Indicator of Compromise)
Evidence that a system has been breached. Examples: unusual network traffic, suspicious file hashes, known malicious IPs, unexpected registry changes.
NAC (Network Access Control)
Security approach that restricts unauthorized devices from connecting to a network. Enforces compliance policies before granting access.
NASL (Nessus Attack Scripting Language)
Programming language used to write custom vulnerability checks for Nessus scanner. Similar to C programming language.
Nessus
Commercial vulnerability scanner developed by Tenable. Uses plugin-based approach to detect security weaknesses in systems, networks, and applications.
Nmap
Network Mapper - open-source tool for network discovery, port scanning, OS detection, and vulnerability scanning using NSE (Nmap Scripting Engine) scripts.
OpenVAS
Open Vulnerability Assessment System - free, open-source vulnerability scanner. Alternative to commercial scanners like Nessus.
Process Explorer
Microsoft Sysinternals tool providing advanced process monitoring. Shows process trees, DLL analysis, network connections, and handle inspection.
Protocol/Port Mismatch
IoC where traffic uses a protocol that doesn't match the expected port. Example: DNS queries on port 80 instead of port 53, indicating potential malware.
Reverse Shell
Attack technique where victim system initiates connection to attacker (instead of attacker connecting in), bypassing firewall restrictions and providing command-line access.
Rogue Device
Unauthorized hardware or software on a network. Examples: rogue access points, personal laptops, malicious VMs, unsecured IoT devices.
Rogue WAP (Wireless Access Point)
Unauthorized wireless access point that mimics legitimate networks. Used for traffic interception, credential theft, and on-path attacks. Example: Wi-Fi Pineapple.
Sinkhole
Technique for redirecting malicious traffic to a null destination where it's absorbed and analyzed, preventing it from reaching intended targets.
Sysinternals
Suite of advanced Windows utilities from Microsoft. Includes Process Explorer, Process Monitor, TCPView, Autoruns, and other diagnostic tools.
