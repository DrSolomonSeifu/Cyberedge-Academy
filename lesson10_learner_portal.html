🔍 Analysis Tools & Techniques

Packet Capture with Wireshark

What is Wireshark?
Wireshark is a free, open-source packet analyzer that captures and displays network traffic in real-time. It's like having X-ray vision for your network—you can see every conversation between computers.

Key Features:

  • Live Capture: Watch network traffic as it happens
  • Protocol Analysis: Understand HTTP, DNS, TCP, and hundreds of other protocols
  • Display Filters: Focus on specific traffic types
  • Follow Streams: Reconstruct entire conversations
  • Export Capabilities: Save captures as PCAP files for later analysis

Wireshark Interface Layout

Pane What It Shows Use Case
Top - Packet List All captured packets with time, source, destination, protocol Quick overview, spot patterns, find suspicious traffic
Middle - Packet Details Layer-by-layer breakdown of selected packet Deep protocol analysis, understand packet structure
Bottom - Packet Bytes Raw hexadecimal and ASCII data Forensic analysis, finding hidden data
🔬 Try It Yourself: Wireshark Basics
  1. Install Wireshark - Download from wireshark.org (free)
  2. Select your network interface - Usually Wi-Fi or Ethernet
  3. Start capturing - Click the blue shark fin icon
  4. Generate traffic - Visit http://example.com in your browser
  5. Stop capture - Red square button
  6. Apply filter - Type http in the filter bar
  7. Find HTTP GET request - Look for request to example.com
  8. Right-click → Follow → HTTP Stream - See the full conversation

Common Display Filters

# Show only HTTP traffic http # Show traffic to/from specific IP ip.addr == 192.168.1.100 # Show DNS queries dns # Show only SYN packets (connection attempts) tcp.flags.syn == 1 # Show traffic on specific port tcp.port == 443

WHOIS - Domain Investigation

What is WHOIS?
WHOIS is like a phone book for the internet. It tells you who owns a domain, when it was registered, and how to contact them. Security analysts use it to investigate suspicious websites and track down threat actors.

Information WHOIS Provides:

  • Domain Owner: Organization or individual name
  • Registration Date: When was the domain created?
  • Expiration Date: When does registration expire?
  • Registrar: Company that registered the domain
  • Name Servers: DNS servers for the domain
  • Contact Information: Email, phone (often privacy-protected)
🔍 Investigate a Suspicious Domain
Red Flags to Look For:
  1. Recently Registered: Domains created in last 30-90 days are often suspicious
  2. Privacy Protection: Hidden owner information can indicate shady activities
  3. Mismatched Information: Location doesn't match claimed organization
  4. Unusual Registrar: Registered through services known for abuse
  5. Short Expiration: Only registered for 1 year (vs legitimate sites with 5-10 years)
Try it: Use who.is or whois.domaintools.com to look up any suspicious domain

The Strings Command

What it does: Extracts readable text from binary files (like malware executables)

# Basic usage strings suspicious.exe # Show strings at least 10 characters long strings -n 10 malware.bin # Search for URLs strings malware.exe | grep "http" # Find IP addresses strings malware.exe | grep -E "[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}"

What you might find:

  • Command and Control (C2) server URLs
  • Hardcoded IP addresses
  • File paths the malware uses
  • Error messages or debug strings
  • Encryption keys or passwords

⚔️ Attack Frameworks

The Cyber Kill Chain

Understanding the Kill Chain
The Cyber Kill Chain breaks down cyberattacks into 7 distinct stages. Understanding these stages helps defenders identify where to intervene and stop attacks before they succeed.
Stage Attacker Actions Defender Response
1. Reconnaissance Gather information about target Monitor for scanning, use deception
2. Weaponization Create malware or exploit Threat intelligence, sandboxing
3. Delivery Send payload to victim Email filtering, user training
4. Exploitation Trigger vulnerability Patching, endpoint protection
5. Installation Install malware, create backdoor Application whitelisting, EDR
6. Command & Control Establish C2 channel Firewall rules, network monitoring
7. Actions on Objectives Achieve goal (steal, destroy, disrupt) DLP, backups, incident response

Key Insight: Breaking the chain at ANY stage stops the attack. The earlier you intervene, the less damage occurs.

MITRE ATT&CK Framework

What is ATT&CK? Adversarial Tactics, Techniques, and Common Knowledge - a comprehensive knowledge base of real-world attacker behavior.

The 14 Tactics (Why attackers do things):

  1. Reconnaissance - Gather information
  2. Resource Development - Prepare infrastructure
  3. Initial Access - Get inside
  4. Execution - Run malicious code
  5. Persistence - Maintain access
  6. Privilege Escalation - Get higher permissions
  7. Defense Evasion - Avoid detection
  8. Credential Access - Steal credentials
  9. Discovery - Learn about the environment
  10. Lateral Movement - Spread through network
  11. Collection - Gather data
  12. Command and Control - Communicate with infected systems
  13. Exfiltration - Steal data
  14. Impact - Disrupt operations
🎯 Using MITRE ATT&CK
Practical Applications:
  1. Map detected attacks: Identify which techniques attackers used
  2. Gap analysis: Find blind spots in your defenses
  3. Threat hunting: Proactively search for specific techniques
  4. Purple teaming: Red team uses techniques, blue team detects them
  5. Tool selection: Choose security tools based on technique coverage
Explore: Visit attack.mitre.org to browse the full matrix

📧 Email Analysis

Why Email Analysis Matters

Critical Statistics:

  • 90%+ of cyberattacks start with email
  • Phishing is the #1 initial access method
  • Business Email Compromise (BEC) costs billions annually
  • Email headers contain forensic evidence attackers can't easily hide

Email Header Analysis

Key Headers to Check:

Header What It Shows Can It Be Spoofed?
From Claimed sender address ✓ Yes - Easy to fake
Return-Path Where bounces should go ⚠️ Harder to fake
Received Each mail server's handling ✗ Added by real servers
X-Originating-IP Sender's IP address ⚠️ Harder to fake
Authentication-Results SPF, DKIM, DMARC results ✗ Added by receiver

SPF, DKIM, and DMARC

SPF (Sender Policy Framework)
What it does: Specifies which mail servers can send email for a domain
Analogy: Like a guest list at a party - only approved servers can send mail
Check: Look for "SPF: PASS" in Authentication-Results header
DKIM (DomainKeys Identified Mail)
What it does: Digital signature proving email hasn't been altered
Analogy: Like a wax seal on an envelope - if broken, it's been tampered with
Check: Look for "DKIM: PASS" in Authentication-Results header
DMARC (Domain-based Message Authentication, Reporting, and Conformance)
What it does: Tells receivers what to do if SPF/DKIM fail
Policy Options: none (monitor), quarantine (spam folder), reject (block)
Check: Look for "DMARC: PASS" in Authentication-Results header
🔍 Analyzing a Suspicious Email
Step-by-Step Investigation:
  1. View Full Headers - In Gmail: More (⋮) → Show original
  2. Check SPF/DKIM/DMARC - Look for "FAIL" results
  3. Examine "Received" Headers - Read bottom to top (reverse chronological)
  4. Check X-Originating-IP - WHOIS lookup on this IP
  5. Verify Return-Path - Does it match the "From" domain?
  6. Analyze Links - Hover (don't click!) to see real destination
  7. Check Attachments - Scan with VirusTotal if suspicious
Red Flags:
  • SPF/DKIM/DMARC failures
  • "From" domain doesn't match originating server
  • Recently registered domain (WHOIS check)
  • Unusual sending country for claimed organization
  • Mismatched link URLs
  • Suspicious attachment file types (.exe, .vbs, .js)

📖 Glossary of Key Terms

Quick reference for important terminology used in this lesson.

ATT&CK (Adversarial Tactics, Techniques, and Common Knowledge)
A knowledge base maintained by MITRE that catalogues real-world attacker behaviors, tactics, and techniques used in cyberattacks.
Base64 Encoding
A binary-to-text encoding scheme used to safely transmit binary data through text-based systems. Commonly used in emails and by attackers to obfuscate malicious content.
C2 (Command and Control)
A channel through which attackers communicate with compromised systems to send commands and receive stolen data.
Cyber Kill Chain
A 7-stage framework developed by Lockheed Martin that describes the phases of a cyberattack: Reconnaissance, Weaponization, Delivery, Exploitation, Installation, Command & Control, and Actions on Objectives.
DKIM (DomainKeys Identified Mail)
An email authentication method that uses cryptographic signatures to verify that an email hasn't been altered during transmission.
DMARC (Domain-based Message Authentication, Reporting, and Conformance)
An email authentication protocol that builds on SPF and DKIM, telling receiving servers what to do if authentication fails and providing reporting mechanisms.
EDR (Endpoint Detection and Response)
Security solution that continuously monitors endpoints (workstations, servers) for malicious activity, providing detection, investigation, and response capabilities beyond traditional antivirus.
IoC (Indicator of Compromise)
Evidence that a system has been breached or infected, such as unusual network traffic, suspicious file hashes, or known malicious IPs.
Lateral Movement
Techniques attackers use to move through a network after initial compromise, accessing additional systems and escalating privileges.
MTA (Message Transfer Agent)
A mail server responsible for routing and delivering email messages across the internet using protocols like SMTP.
PCAP (Packet Capture)
A file format for saving captured network packets, commonly used with Wireshark and tcpdump for network analysis and forensics.
Phishing
Social engineering attack that uses deceptive emails to trick recipients into revealing sensitive information or executing malicious code.
Reverse Shell
A technique where the victim system initiates an outbound connection to the attacker, bypassing firewall restrictions and giving the attacker command-line access.
SIEM (Security Information and Event Management)
A centralized security solution that collects, correlates, and analyzes log data from across an organization to detect threats and support incident response.
SPF (Sender Policy Framework)
An email authentication method that specifies which mail servers are authorized to send email for a domain, helping prevent email spoofing.
Strings Command
A Unix/Linux utility that extracts printable character sequences from binary files, useful for analyzing malware and finding embedded URLs or IP addresses.
tcpdump
A command-line packet capture tool for Unix/Linux systems, similar to Wireshark but without a GUI, ideal for remote servers and automation.
TTP (Tactics, Techniques, and Procedures)
Patterns of behavior that characterize how threat actors operate, including their goals (tactics), methods (techniques), and specific implementations (procedures).
WHOIS
A query protocol that provides information about domain registration, including owner, registration date, and contact information.
Wireshark
Free, open-source packet analyzer with a graphical interface, widely used for network troubleshooting, analysis, and security investigations.
