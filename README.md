## About

CyberEdge Academy is a complete, self-paced cybersecurity analyst training platform built on the **Anchor & Apply instructional framework** developed by Solomon Seifu, PhD. The platform covers the full spectrum of cybersecurity analyst skills through 14 interactive lesson portals.

---

## Package Contents

| File | Description |

## Quick Start

1. Keep all files in the **same folder**
2. Open `START_HERE.html` in Chrome or Edge
3. Click **Launch CyberEdge Academy**
4. Navigate lessons from the sidebar or lesson grid

Works offline after first load (PWA).
