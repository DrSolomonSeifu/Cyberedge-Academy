Installation Guide

How to run CyberEdge Academy on Windows, Mac, Linux, and Android/iOS — by Dr. Solomon Seifu

🖥️
Windows
Windows 10 / 11
  1. Extract the ZIP file to any folder (e.g. Desktop)
  2. Double-click LAUNCH_WINDOWS.bat to open in Chrome or Edge
  3. In the browser address bar, click the install icon (⊕) to install as a desktop app
  4. The app will appear in your Start Menu and Desktop as a standalone application
Tip: Right-click the .bat file → "Run as Administrator" if your browser doesn't launch automatically.
🍎
macOS
macOS 12 Monterey or later
  1. Extract the ZIP file to your Applications or Desktop folder
  2. Open Terminal, navigate to the folder:
    cd ~/Desktop/CyberEdge_Academy
  3. Run: chmod +x LAUNCH_MAC.sh && ./LAUNCH_MAC.sh
  4. Or simply double-click CyberEdge_Master_Portal.html to open in your default browser
  5. In Chrome, click Install (⊕) in the address bar for a native app experience
Tip: If macOS blocks the .sh file, go to System Settings → Privacy & Security → Allow.
📱
Android
Android 8.0 or later
  1. Host the folder on a web server or upload to GitHub Pages (free)
  2. Open Chrome for Android and navigate to the hosted URL
  3. Tap the three-dot menu (⋮) → "Add to Home Screen"
  4. Tap Install — the app icon appears on your home screen
  5. Works fully offline after the first visit
Alternative: Transfer the ZIP to your phone, extract it, and open the HTML file directly in Chrome for Android.
📲
iPhone / iPad
iOS 14 or later
  1. Host the folder on GitHub Pages and open the URL in Safari
  2. Tap the Share button (↑) at the bottom of the screen
  3. Scroll down and tap "Add to Home Screen"
  4. Tap Add — the app icon appears on your home screen like a native app
  5. Works offline after the first load
Note: iOS requires Safari for PWA installation. Chrome on iOS cannot install PWAs.
🐧
Linux
Ubuntu, Debian, Fedora
  1. Extract the ZIP to your home or applications directory
  2. Open Terminal and run:
    chmod +x LAUNCH_LINUX.sh && ./LAUNCH_LINUX.sh
  3. Or open CyberEdge_Master_Portal.html directly in Chrome/Chromium
  4. Click the install icon in Chrome's address bar to install as a PWA
Tip: Chrome on Linux provides the best PWA experience with full offline support.
🌐
GitHub Pages
Free web hosting for the app
  1. Create a GitHub repository and upload all files
  2. Go to Settings → Pages in your repository
  3. Under Source, select main branch → / (root) → Save
  4. Your app is live at yourusername.github.io/repo-name
  5. Share the URL — anyone can access and install it on any device
Best approach: GitHub Pages hosting enables Android and iOS installation without any server setup.

Recommended GitHub Publishing Steps

STEP 1 Create a new public repository named cyberedge-academy on GitHub

STEP 2 Upload all files. Make sure CyberEdge_Master_Portal.html and all lesson files are in the root of the repo

STEP 3 Rename CyberEdge_Master_Portal.html to index.html so it loads automatically when visiting the URL

STEP 4 Enable GitHub Pages (Settings → Pages → Source: main/root). Wait 2–3 minutes for deployment

STEP 5 Share your live URL on LinkedIn with a post crediting your Anchor & Apply framework and PhD background

STEP 6 Pin the repository to your GitHub profile for maximum visibility
